Level Up 2: Real Code Quest

The sequel to the first Level Up book. Students read their own game as real code, then rebuild their hero in Godot 4.

Coming soon. Not for sale yet. Levels 1–2 work in Chrome, so a Chromebook is fine for those two levels. Levels 3–10 need a Windows, Mac, or Linux computer, because those levels use Godot 4.

Level 1 of Real Code Quest is free. It is the first lesson, Peek Behind the Blocks, not the full book. The rest of the book is coming soon.

What the student builds

Level Up 2: Real Code Quest is the next manual after Level Up: Make Your First Game with AI. A parent runs the lessons. Any AI help stays on the parent's account.

The book has 10 levels. Each level ends in something playable.

In Levels 1–2, students open their own MakeCode Arcade game and read it as JavaScript and Python. In Levels 3–10, they rebuild that same hero in Godot 4 with GDScript.

They finish with the same hero, rebuilt in Godot as a 3-level platformer, plus one new move they design, such as a dash, a wall climb, a double jump, or a grappling vine.

Ages

About 10–14, after Level Up 1, or once they are comfortable in MakeCode Arcade. Steady typing helps.

The 10 levels

These are the lesson names already on the learning path. Levels 1–2 stay in the browser. Levels 3–10 move to Godot 4.

  1. Level 1 Peek Behind the Blocks

    Chrome, including a Chromebook. Students start reading their MakeCode Arcade game as JavaScript and Python. Download this free lesson.

  2. Level 2 Type It Yourself

    Chrome, including a Chromebook. Students type the JavaScript and Python themselves. This is the last level that stays in the browser.

  3. Level 3 New World: Godot Basics

    Windows, Mac, or Linux. Students open Godot 4 and start rebuilding their hero in GDScript.

  4. Level 4 Hero in Motion

    The hero moves in Godot 4, written in GDScript.

  5. Level 5 Build the World

    Students build the game world in Godot 4.

  6. Level 6 Friends and Foes

    Other characters join the Godot game.

  7. Level 7 Score, Lives and Screens

    Score, lives, and screens, in GDScript.

  8. Level 8 Save the Day

    The hero's goal, still in Godot 4.

  9. Level 9 Juice 2.0

    Sound, feel, and polish in Godot 4.

  10. Level 10 Export and Playtest

    Godot 4 and GDScript, on a Windows, Mac, or Linux computer. Students export the game and playtest it.

What you need

Levels 1–2 work in Chrome. Chromebooks are OK. Students use MakeCode Arcade in the browser and read their game as JavaScript and Python. A child does not need an account to start.

Levels 3–10 need a Windows, Mac, or Linux computer. Those levels use Godot 4, which you install. Opening the editor does not ask for your child's name, email, or a login. A Chromebook covers Levels 1–2 only.

Godot is free and open source. If typing still feels like a lot, GDevelop is a gentler desktop option that can run with no account. The lessons themselves use Godot 4 and GDScript. Any AI use stays on the parent's account.
