How we rank

Tier lists are only useful if you can trust them. Here are the rules we follow.

Hands-on tests

Each tool in a category runs the same real task, such as "build this to-do app" or "make a 32×32 knight sprite." We record the output, the time taken, and the cost.

Dated verdicts

Every grade shows when it was tested. When a tool ships a major update, we test it again. Old grades stay visible, so you can see what changed.

Never for sale

Sponsors can buy a labeled ad slot. They can't buy a grade. Affiliate links never change a ranking.

Request a Respawn

Tell us what broke. We'll reply with a quote and a time estimate before any work starts. Don't paste API keys or passwords here.

We'll ask for repo access with limited permissions only if you accept the quote. We never store your secrets.
