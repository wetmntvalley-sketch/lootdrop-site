Star Catcher

A practice game you can import into MakeCode Arcade.

This is the Level 1 practice game, saved as a picture file. Use it if you don't have your own Level 1 game yet.

What this file is

Star Catcher is a small practice game from Level 1 of Level Up: Make Your First Game with AI. The title screen says “Find the goal!” and the version on the screen is v1.1.

The download looks like an ordinary PNG picture. MakeCode Arcade can read a whole game tucked inside that picture. People call this kind of file a cartridge. You import the picture, and the editor opens the game.

Who it's for

This file is for students getting ready for Level Up 2: Real Code Quest. Level Up 2 is coming soon. Some of its lessons start from a Level 1 game. If you already built your own, keep using that one. It is yours.

If you don't have a Level 1 game on this computer, download Star Catcher and follow along with this practice copy.

Download the file

Click the button. The file name is star-catcher-practice.png. Leave the name like that, and keep the .png ending.

Download star-catcher-practice.png

The file lives at this address, so a book or a note can point straight at it:

https://levelupmakers.com/downloads/star-catcher-practice.png

That link downloads the file. It should save to your computer, the way a PDF does, instead of only showing the picture in the tab.

If the picture opens on the screen anyway, come back to this page. Right-click the download button. On a phone or tablet, press and hold it. Choose Save link as or Download linked file. Save it in Downloads, or in another folder a grown-up can find.

Use the original file

MakeCode needs the picture you downloaded. A screenshot, or a new copy saved from a photo app, can drop the hidden game. Then Import File has nothing to open. Download it here, and import that file.

Import it into MakeCode Arcade

A grown-up can sit with you for these steps. You need a computer with a web browser. Nothing to install, and no account.

  1. Open arcade.makecode.com.
  2. Click Import.
  3. Click Import File.
  4. Choose star-catcher-practice.png.
  5. MakeCode opens Star Catcher. Play it in the simulator on the left, then look at the blocks.

You can also drag the PNG onto the MakeCode editor. Drop the file on the page, and MakeCode imports it.

After it opens

Play the game, then peek at how it is built. You can change it. MakeCode keeps the project in this browser on this computer. To keep a backup, use the save icon in MakeCode, the same way Level 1 describes.

Leave real names, school, and town out of the project. This page does not ask for them. A public share link can wait for the sharing checklist in Level 10 of the first book.

Want to build your own first?

Star Catcher is a spare game so you can practice. It does not replace Level 1. Level 1 is free to read and print. In that chapter you invent your own hero and make a tiny game yourself. The full manual is on the book page.
